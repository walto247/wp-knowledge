# Block themes (theme.json)

Status: **generic parts checked 2026-10-17** against the theme.json schema (schemas.wp.org/trunk/theme.json), the WordPress Theme Handbook (theme structure, style variations, typography) and the WordPress 7.1 dev note on responsive styles (`SOURCES.md`). The master theme's own decisions live in `wp-master-theme/docs/`; this file holds only what is true for any block theme.

## Files and folders (fact)

- Required: `style.css` (theme header) and `templates/index.html`.
- `theme.json` (settings and styles), `functions.php`, `screenshot.png` (1200 × 900) are optional but normal.
- `templates/` (block markup `.html`), `parts/` (template parts: header, footer), `patterns/` (PHP files with a header comment, registered automatically), `styles/` (style variations as JSON).

## theme.json (fact)

- `"version": 3` is current (version 2 is still accepted; no version means 1); `"$schema": "https://schemas.wp.org/trunk/theme.json"` gives editor hints. There is no version 4. The handbook's intro page still shows version 2: trust the schema.
- Top-level keys: `settings`, `styles`, `customTemplates`, `templateParts`, `patterns`, plus `title`, `slug`, `description`, `blockTypes` (for partial style-variation files).
- `settings.appearanceTools: true` switches on border, colour, spacing, typography and position controls (default off).
- **Colour:** `settings.color.palette[] {name, slug, color}` → CSS variable `--wp--preset--color--<slug>`; `defaultPalette: false` hides WordPress's own colours.
- **Typography:** `fontFamilies[] {name, slug, fontFamily, fontFace}` (self-hosted fonts in `fontFace`); `fontSizes[] {name, slug, size, fluid}`; `settings.typography.fluid` turns on fluid sizes (`clamp()` generated by WordPress); `defaultFontSizes: false`.
- **Spacing:** `spacingSizes[] {name, slug, size}` or a generated `spacingScale`; `defaultSpacingSizes: false`.
- **Layout:** `settings.layout.contentSize` (reading width) and `wideSize` (wide blocks); use our defaults from `../design/general.md` (Japanese reading column about 41em; content 1120 px).
- **Styles:** `styles.color`, `typography`, `spacing`, `border`, `shadow`, `css`; `styles.elements` (link, button, h1–h6, caption); `styles.blocks` per block; `styles.variations` for block style variations.
- **Style variations:** JSON files in `styles/` with `version`, `title`, `settings`, `styles`; a per-site child theme can change look by variation without code.
- **WordPress 7.1:** responsive overrides inside block styles (`@tablet`, `@mobile`; desktop is the default) with breakpoints set in `settings.viewport` (WordPress defaults 480 / 782 px), and `:hover` styles inside those responsive overrides. Our breakpoint is 768 (`../design/general.md`): set it in `settings.viewport` when the master theme uses this.

## Default themes (fact)

Twenty Twenty-Five is the latest year-named default theme; there is no Twenty Twenty-Six. WordPress 7.2 (2026-12-08) is planned to ship a new default theme; the proposal under test is **Ipsum** (year names dropped).

## Our defaults for any block theme (practice, from the other topics)

- Japanese body 16 px, line height 1.7–1.75, letter spacing 0.02 em, `line-break: strict`, font stack from `../design/japan.md`; headings 1.4.
- Tap targets 44 × 44 px; contrast per `../design/accessibility.md`.
- Follow the designer's render exactly; the visitor comes first (owner rules in `../design/general.md`).
